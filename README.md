## 📌 About the Internship

The internship focused on building a practical foundation in modern AI concepts and data analytics through the Cisco Networking Academy platform, accessed via IILM University. It combined three self-paced courses covering AI/LLM fundamentals, applied AI for customer-review analysis, and core data analytics, each verified with an individual course completion certificate.

**Organization:** IILM University, Greater Noida, through the Cisco Networking Academy program.

---

## 🎯 Objectives

- Explain basic concepts in AI and Machine Learning
- Use photo apps to classify objects and explain how object detection and image segmentation work
- Explain the nuances and limitations of using AI for language translation
- Understand how large language models (LLMs) work and how to prompt them effectively
- Explore LLM-enabled chatbot use cases: idea generation, summarization, rewording, and grading
- Apply AI techniques to analyze and interpret customer review text
- Strengthen core data analytics skills and evidence-based reasoning
